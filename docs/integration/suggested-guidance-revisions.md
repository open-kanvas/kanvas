# Suggested guidance revision guards
Save, delete and explicit import follow the shared optional numeric revision contract. Omitting expectedRevision applies to current state inside the serialized transaction; explicit0 is create-only, and any explicit stale revision fails. To import exactly what was previewed, send that preview revision. Omitted import copies current content of the explicitly selected suggestion into a NEW personal prompt; it never overwrites or activates. Request IDs remain payload-bound and retries preserve the first result. Service-admin checks for global edits/deletion and full-account access are unchanged.
