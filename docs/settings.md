# Live settings

The settings display saves each owner/editor selection immediately; no Apply button is needed. Contributing guests can request a change but cannot write settings. Agent updates also refresh an open settings display. Revisions still reject conflicting writes.

Choose **This session** or **All new sessions** before editing. The latter saves account defaults, not every existing session. Existing standalone sessions retain their settings. Group-inherited sessions retain their documented inheritance rules and explicit overrides. Open settings refresh account defaults; when viewing session scope they show an account-update notice without silently switching scope or pretending the session changed. Select All new sessions to inspect the saved defaults.

Ocean, dark theme, Ocean-blue accent, 22px reading text, 220 words/minute, and 100% zoom are the system defaults. Regional source/device defaults are labelled. The 22px option remains available after selecting another size.

Zoom presets and Exact zoom factor are two inputs for the same readingZoom value, not separate settings. 1 means 100%; the permitted factor is 0.75–1.75.

There is no application-wide comfortable/compact density setting. Stored legacy density fields are ignored at the storage boundary; old density-only settings views become the full settings view. Template-specific layout options are independent of global appearance.
