# Reviewed signage artwork

The 88 offered sign types use 55 exact unmodified Google Material Symbols SVG files from repository revision `10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7`, Apache-2.0. See [/signage/credits.html](../public/signage/credits.html) and [/signage/manifest.json](../public/signage/manifest.json) for every sign disposition, author, source file, commit, chosen license and SHA-256. LICENSE and NOTICE accompany distribution.

The other 49 original self-made types are retired from schema/catalog/rendering. Their historical saved source remains untouched and renders an honest unavailable message, never a fallback glyph. In particular, ISO/national safety and traffic artwork, general prohibition/no-smoking conflicts, and share-alike candidates remain excluded pending qualified rights review. The catalog does not certify any sign for legally required safety use. Existing region labels, 13 directional variants, grouped layouts and live fields are preserved; source SVG bytes are not recoloured or edited. Direction/text layers stay separate.

The source repository provides general-information icons, not ISO variants. No new sign was redrawn. Historical ASL playback is withdrawn; no template, assets or dependency was found in the baseline and none is introduced.
