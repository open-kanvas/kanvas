# Supplied statistical visuals
Venn template: sets has two/three labeled entries, mapped in order to A/B/C. Regions are disjoint cells: outside,A,B,AB,C,AC,BC,ABC; three-set-only IDs are rejected for two sets. Regions accepts supplied label/value/members; When no value/label is supplied, member names are shown (truncated to fit); full members are available in SVG title/current state. Emphasis lists exact cell IDs. Union/intersection/complement are selected by the external agent, not inferred. Region area is not proportional to counts. All cells use high-contrast outlines; custom set colors affect outlines.
Use normal submit/current and view.patch set /data/emphasis, /data/regions/AB/value etc. Clear with emphasis:[].

Existing chart template kind line adds optional distribution:{ranges:[],bands:[]}. Supply numeric strictly increasing x/y observations, at least two per series. Ranges: {id,series,from,to,label?,color?}; bands: {id,series,points:[{x,low,high}],label?,color?}. Ranges clip straight supplied polyline segments at exact x boundaries. This is rendering interpolation, not fitting, integration, probabilities or density generation. Intervals must lie within the named series x extent. Band bounds are entirely supplied, independent of curve observations. Multiple curves retain distinct colors/optional dashes, bands dashed edges and lighter fill. Patch one range/band using its current array index, or replace ranges/bands arrays; read current state for indices. Stable overlay IDs are retained for inspection, not a separate selector API.
Distribution mode intentionally excludes dataset binding, stacking, secondary axes and legacy composable axis overrides. Existing charts without distribution are unchanged.
VITE_KANVAS_STATISTICS_ENABLED=false disables both renderers at build time without deleting data. No dependency or migration; revert independently of math. The fixed per-session retained-view limit applies; publishing after navigating back preserves forward history. No inferred statistics, memberships or plot-linked math. Browser/hardware acceptance remains separate.
